Dynamite TTS — what this installer includes

INCLUDED (always)
• Dynamite TTS tray app (self-contained; no separate .NET install)
• Phonon speech engine + the Phonon 31M English model (Gradium, Apache 2.0): the default local
  voice, with ~100 downloadable voices (Verbatim mode works offline after install)
• Kokoro voices (the alternative engine under Settings → Inference Engine)

OPTIONAL (next page — you can opt out)
• Lemonade Server (AMD) — needed for Summary and Explain modes (process selection, then speak).
  Installed via winget if you leave the option checked. The small default chat model is
  downloaded later, the first time you use Summary or Explain mode (not during this Setup).

LATER / ON DEMAND (not installed here)
• Kokoro speech model (325 MB) — downloaded once, the first time you choose Kokoro
• NVIDIA CUDA runtime (~1 GB) — downloaded once if you enable GPU-accelerated speech with Kokoro
• Larger Lemonade chat models — you can pull them yourself in Lemonade if you want

Hardware notes
• Phonon runs on the CPU only and needs an x86-64-v3 processor (AVX2; Intel Haswell / AMD
  Excavator from 2013-2015 or newer). First audio in well under 0.1 s, about 10x realtime.
  On older processors the app uses Kokoro instead and downloads its model on first use.
• Verbatim (Kokoro) works on any supported 64-bit Windows 10/11 PC (CPU; GPU optional).
• Summary / Explain need Lemonade + enough RAM for a small local LLM. AMD NPU/GPU is optional
  and only makes chat faster — it is not required for the default tiny model.

Privacy: spoken/summarized/explained text stays on this machine when using local Kokoro or Phonon and local Lemonade.
